<h3 id="were-integrated-with-n8n-again">We're integrated with N8N (Again!)</h3>



You've seen this announcement once before

This time, the [Skyvern node](https://n8n.io/integrations/skyvern/) is a **verified node** that you can access via **n8n cloud** :) n8n is a workflow automation platform that empowers technical teams to build complex, multi-step workflows using their 400+ native integrations.



<h3 id="why-integrate-into-n8n">Why Integrate into n8n?</h3>



There has been a lot of overlap between Skyvern users and n8n users. So, we’ve made an integration that connects the two more easily.

Here’s what we know: people often connect n8n to Skyvern because they serve different purposes: n8n excels at connecting applications with APIs while **Skyvern allows you to automate on sites without APIs.** With this integration, you can now do both.

Here are some real use cases from users connecting n8n and Skyvern:

-   [Ben AI](https://www.youtube.com/watch?v=FhDYo2VKu5E) created a WhatsApp voice agent that can automatically purchase items, submit, forms, and apply to jobs by connecting n8n to Skyvern
-   Scrape and extract hundreds job postings using n8n and automate mass application submission in Skyvern
-   Automating account and enrollment creation in CRMs triggered by n8n
-   Retrieve invoices using Skyvern, parse, and auto-populate the data in your Google Sheets using n8n

Happy Automating!
