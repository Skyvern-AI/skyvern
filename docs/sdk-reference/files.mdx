## upload_file

Upload a file

<Warning>
The `upload_file` method in the current Python and TypeScript SDKs does not send the file's contents: it posts `file` as a text field, and the API rejects the request with a 422 error. Until the SDKs are fixed, call the REST endpoint directly with a multipart upload:

<CodeGroup>
```bash curl
curl -X POST https://api.skyvern.com/v1/upload_file \
  -H "x-api-key: $SKYVERN_API_KEY" \
  -F file=@invoice.pdf
```

```python Python
import httpx

with open("invoice.pdf", "rb") as f:
    response = httpx.post(
        "https://api.skyvern.com/v1/upload_file",
        headers={"x-api-key": "YOUR_API_KEY"},
        files={"file": ("invoice.pdf", f)},
    )
response.raise_for_status()
print(response.json())
```
</CodeGroup>
</Warning>
