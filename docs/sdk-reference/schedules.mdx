## schedules.create

Create a cron, fixed-interval or one-time schedule that runs the given agent automatically with a fixed set of parameters. An interval schedule first runs at first_fire_at, or one interval after creation. A one-time schedule runs once at run_at. Returns the stored schedule and its next upcoming run times.

<CodeGroup>
```python Python
await skyvern.schedules.create(
    workflow_permanent_id: str,
    *,
    timezone: str,
    cron_expression: str | None = ...,
    interval_seconds: int | None = ...,
    first_fire_at: datetime | None = ...,
    run_at: datetime | None = ...,
    enabled: bool | None = ...,
    parameters: dict[str, Any | None] | None = ...,
    name: str | None = ...,
    description: str | None = ...,
) -> WorkflowScheduleResponse
```

```typescript TypeScript
skyvern.schedules.create(workflowPermanentId: string, request: WorkflowScheduleUpsertRequest): Promise<WorkflowScheduleResponse>
```
</CodeGroup>

**Parameters**

| Parameter | TypeScript | Type | Required | Default | Description |
|---|---|---|---|---|---|
| `workflow_permanent_id` | `workflowPermanentId` | `str` | Yes | — | ID of the agent (`wpid_…`). |
| `timezone` | `timezone` | `str` | Yes | — |  |
| `cron_expression` | `cron_expression` | `str \| None` | No | — |  |
| `interval_seconds` | — | `int \| None` | No | — | Fixed elapsed interval between runs, in seconds. Mutually exclusive with cron_expression. |
| `first_fire_at` | — | `datetime \| None` | No | — | First run of an interval schedule; later runs follow every interval_seconds from it. Must be in the future when changed. Defaults to one interval after creation. |
| `run_at` | — | `datetime \| None` | No | — | Run the agent once at this instant, ISO 8601 with a UTC offset, at least 60 seconds in the future. Mutually exclusive with cron_expression and interval_seconds; the schedule can be edited or canceled only until it fires. |
| `enabled` | `enabled` | `bool \| None` | No | — |  |
| `parameters` | `parameters` | `dict[str, Any \| None] \| None` | No | — |  |
| `name` | `name` | `str \| None` | No | — |  |

</Accordion>
