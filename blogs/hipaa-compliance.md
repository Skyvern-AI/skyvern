<h2 id="hipaa-compliance">HIPAA Compliance</h2>



Skyvern is now HIPAA Compliant!!

This has been a long time coming

We've known that we would have to become HIPAA compliant for a long time. We kept talking to healthcare company after healthcare company.. all with the same painpoint

"I need help integrating with the highly fractured EHR ecosystem"

So.. we open sourced

...And it helped for a bit. Some companies started to self-host us

But it was too high friction.
