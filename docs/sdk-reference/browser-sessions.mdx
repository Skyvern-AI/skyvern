A browser session is a cloud browser that stays open between runs, so tasks and agents can share cookies and page state. Pass its `browser_session_id` (`pbs_…`) to `run_task` or `run_workflow`.

Every method here also accepts `request_options` (Python) or a final `requestOptions` argument (TypeScript) to override the timeout, retries or headers for one call; see [request options](/sdk-reference/overview#request-options).

**Parameters**

| Parameter | TypeScript | Type | Required | Default | Description |
|---|---|---|---|---|---|
| `url` | `url` | `str \| None` | No | — | Optional URL to open when the standalone browser session starts. |
| `timeout` | `timeout` | `int \| None` | No | — | Timeout in minutes for the session. Timeout is applied after the session is started. Must be between 5 and 240. Defaults to 60. |
| `proxy_location` | `proxy_location` | `CreateBrowserSessionRequestProxyLocation \| None` | No | — | Geographic Proxy location to route the browser traffic through. This is only available in Skyvern Cloud. |

| `browser_type` | `browser_type` | `PersistentBrowserType \| None` | No | — | The type of browser to use for the session. |
| `browser_profile_id` | `browser_profile_id` | `str \| None` | No | — | ID of a browser profile to load into this session (restores cookies, localStorage, etc.). browser_profile_id starts with `bp_`. |
| `generate_browser_profile` | `generate_browser_profile` | `bool \| None` | No | — | When true, the session's browser profile (cookies, localStorage, etc.) is saved to storage when the session ends so it can be turned into a reusable browser profile. ## extend_browser_session

Extend a live browser session by a number of minutes. Sessions are created with a timeout of at most 240 minutes and can be extended, one or more times, up to a total lifetime of 360 minutes (6 hours). The minutes are added to the session's current deadline. A request for more than the remaining headroom is granted the remainder, and the response carries a warning. The response's `timeout` is the session's new total budget in minutes, counted from when the session started.

<Note>Python only: the TypeScript SDK has no equivalent.</Note>

<CodeGroup>
```python Python
await skyvern.extend_browser_session(
    browser_session_id: str,
    *,
    additional_minutes: int,
) -> BrowserSessionResponse
```
</CodeGroup>

| `additional_minutes` | — | `int` | Yes | — | Minutes to add to the session's current deadline. A session can be extended, one or more times, up to a total lifetime of 360 minutes (6 hours) counted from when it started; a request for more than the remaining headroom is granted the remainder and the response carries a warning. |
