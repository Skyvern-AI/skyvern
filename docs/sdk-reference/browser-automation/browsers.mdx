Browser automation drives a Playwright browser with AI added on top. Start from a `Skyvern` client, get a `SkyvernBrowser`, then a page.

## Launch or connect

### skyvern.launch_cloud_browser

Launch a new cloud-hosted browser session.

This creates a new browser session in Skyvern's cloud infrastructure and connects to it.

<CodeGroup>
```python Python
await skyvern.launch_cloud_browser(
    *,
    timeout: int | None = None,
    proxy_location: ProxyLocationInput = None,
    extensions: list[Extensions] | None = None,
    browser_profile_id: str | None = None,
    browser_type: PersistentBrowserType | None = None,
) -> SkyvernBrowser
```

```typescript TypeScript
skyvern.launchCloudBrowser(options?: { timeout?: number; proxyLocation?: ProxyLocation; }): Promise<SkyvernBrowser>
```
</CodeGroup>

**Parameters**

| Parameter | TypeScript | Type | Required | Default | Description |
|---|---|---|---|---|---|
| `timeout` | `timeout` | `int \| None` | No | `None` | Timeout in minutes for the session. Timeout is applied after the session is started. Must be between 5 and 240; values above 240 are rejected with a 400. Defaults to 60. |
| `proxy_location` | `proxyLocation` | `ProxyLocationInput` | No | `None` | Geographic proxy location to route the browser traffic through. This is only available in Skyvern Cloud. |
| `extensions` | — | `list[Extensions] \| None` | No | `None` | Browser extensions to install in the session. |
| `browser_profile_id` | — | `str \| None` | No | `None` | Browser profile ID to load into the session. |
| `browser_type` | — | `PersistentBrowserType \| None` | No | `None` | Browser engine for the session (msedge, chrome, or stealth-chromium). |

**Returns** `SkyvernBrowser` · TypeScript `Promise<SkyvernBrowser>` — A browser instance connected to the new cloud session.

**Example**

<CodeGroup>
```python Python
import asyncio

from skyvern import Skyvern


async def main() -> None:
    skyvern = Skyvern(api_key="YOUR_API_KEY")
    result = await skyvern.launch_cloud_browser()
    print(result)


asyncio.run(main())
```

```typescript TypeScript
import { Skyvern } from "@skyvern/client";

const skyvern = new Skyvern({ apiKey: "YOUR_API_KEY" });
const result = await skyvern.launchCloudBrowser();
console.log(result);
```
</CodeGroup>

### skyvern.use_cloud_browser

Get or create a cloud browser session.

This method attempts to reuse the most recent available cloud browser session.
If no session exists, it creates a new one. This is useful for cost efficiency
and session persistence.

<CodeGroup>
```python Python
await skyvern.use_cloud_browser(
    *,
    timeout: int | None = None,
    proxy_location: ProxyLocationInput = None,
) -> SkyvernBrowser
```

```typescript TypeScript

```
</CodeGroup>

**Parameters**

| Parameter | TypeScript | Type | Required | Default | Description |
|---|---|---|---|---|---|
| `timeout` | `timeout` | `int \| None` | No | `None` | Timeout in minutes for the session. Timeout is applied after the session is started. Must be between 5 and 240; values above 240 are rejected with a 400. Defaults to 60. Only used when creating a new session. |
| `proxy_location` | `proxyLocation` | `ProxyLocationInput` | No | `None` | Geographic proxy location to route the browser traffic through. This is only available in Skyvern Cloud. Only used when creating a new session. |

### skyvern.launch_local_browser

Launch a new local Chromium browser with Chrome DevTools Protocol (CDP) enabled.

This method launches a browser on your local machine with remote debugging enabled,
allowing Skyvern to control it via CDP. Useful for development and debugging.

<Note>Python only: the TypeScript SDK has no equivalent.</Note>

<CodeGroup>
```python Python

    *,
    headless: bool = False,
    port: int | None = None,
    args: list[str] | None = None,
    user_data_dir: str | None = None,
) -> SkyvernBrowser
```
</CodeGroup>

**Parameters**

| Parameter | TypeScript | Type | Required | Default | Description |
|---|---|---|---|---|---|
| `headless` | — | `bool` | No | `False` | Whether to run the browser in headless mode. Defaults to False. |
| `port` | — | `int \| None` | No | `None` | The port number for the CDP endpoint. Anonymous launches use an OS-assigned port; explicitly configured launches retain DEFAULT_CDP_PORT. |
| `args` | — | `list[str] \| None` | No | `None` | Additional command-line arguments to pass to Chromium. Defaults to None. Example: ["--disable-blink-features=AutomationControlled", "--window-size=1920,1080"] |

**Returns** `SkyvernBrowser` — A browser instance with Skyvern capabilities.

## Pages

### browser.get_working_page

Get the most recent page or create a new one if none exists.

This method returns the last page in the browser context, or creates a new page
if the context has no pages. This is useful for continuing work on an existing
page without creating unnecessary new tabs.

<CodeGroup>
```python Python
await browser.get_working_page() -> SkyvernBrowserPage
```

```typescript TypeScript
browser.getWorkingPage(): Promise<SkyvernBrowserPage>
```
</CodeGroup>

**Returns** `SkyvernBrowserPage` · TypeScript `Promise<SkyvernBrowserPage>` — The most recent page wrapped with Skyvern capabilities.

**Example**

<CodeGroup>
```python Python
import asyncio

from skyvern import Skyvern


async def main() -> None:
    skyvern = Skyvern(api_key="YOUR_API_KEY")
    browser = await skyvern.launch_cloud_browser()
    result = await browser.get_working_page()
    print(result)
    await browser.close()


asyncio.run(main())
```

```typescript TypeScript
import { Skyvern } from "@skyvern/client";

const skyvern = new Skyvern({ apiKey: "YOUR_API_KEY" });
const browser = await skyvern.launchCloudBrowser();
const result = await browser.getWorkingPage();
console.log(result);
await browser.close();
```
</CodeGroup>

    skyvern = Skyvern(api_key="YOUR_API_KEY")

browser session via the API, marking it as completed.
