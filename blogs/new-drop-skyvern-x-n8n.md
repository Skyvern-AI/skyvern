<h3 id="gather-%E2%80%98round">Gather ‘round!</h3>



Our integration in n8n (community node) is finally here! n8n is a workflow automation platform that empowers technical teams to build complex, multi-step workflows using their 400+ native integrations, with an even richer community node ecosystem



<h3 id="why-integrate-into-n8n">Why Integrate into n8n?</h3>



Is it fate? Is it science? Don’t know, but there has been a lot of overlap between Skyvern users and n8n users. So, we’ve made an integration that connects the two more easily.

Here’s what we do know: people often connect n8n to Skyvern because they serve different purposes: n8n excels at connecting various applications and services while Skyvern allows you to automate on sites without APIs.

Here are some real use cases from users connecting n8n and Skyvern:

-   [Ben AI](https://www.youtube.com/watch?v=FhDYo2VKu5E) created a WhatsApp voice agent that can automatically purchase items, submit, forms, and apply to jobs by connecting n8n to Skyvern
-   Scrape and extract hundreds job postings using n8n and automate mass application submission in Skyvern
-   Automating account and enrollment creation in CRMs triggered by n8n
-   Retrieve invoices using Skyvern, parse, and auto-populate the data in your Google Sheets using n8n

Happy Automating!
