<h2 id="launch-jobs-agent">Launch Jobs Agent</h2>



Last month, we brought you the contact form agent. This month, we're excited to share our newest agent with you: The Job Application Agent!

Using it is super simple:

1.  Go to [app.skyvern.com/jobs](http://app.skyvern.com/jobs)
2.  Upload your Resume
3.  Give Skyvern a list of jobs
4.  Sit back, relax, and watch it auto-apply to those jobs for you

This had been an emerging use case for Skyvern, and we wanted to make it even easier for you to use it. A handful of eager users were using Skyvern to apply to jobs automatically, and we thought.. applying to jobs sucks! Maybe we can help demo Skyvern with something we personally hate doing.

So here we are. Go to [app.skyvern.com/jobs](http://app.skyvern.com/jobs), try it out and let us know what you think!

<h2 id="parameter-changes">Parameter Changes</h2>





<h3 id="removing-context-parameters">Removing Context Parameters</h3>



I bet you didn’t even know what they are… and now you won’t have to! We got rid of them. Context parameters were confusing—to you, me, almost every user. Instead of defining them, they can now be referenced in input fields using {{ parameter\_name }} syntax that's common in the industry. More UX to come to improve this and make the concept widely accessible to everyone.

<h3 id="loading-parameterized-fields-with-a-icon">Loading Parameterized Fields with a + Icon</h3>



Previously, we had two ways of loading parameters: using a drop down and by writing the parameter key into parameterized fields. It’s hard to explain and even harder to implement. Instead of writing the parameter key or loading it in a dropdown menu, add a parameter to any input field where there is a + icon.
