Skyvern’s **open source project** just got faster. 🚀

We’ve swapped out **Poetry** for **uv** — the blazing-fast new Python package manager.

That means your builds are now:

-   <strong>Much quicker —</strong> installs and resolves dependencies in a fraction of the time.
-   <strong>Simpler —</strong> no more waiting around for environments to set up.
-   <strong>Future-proof —</strong> leveraging modern tooling to keep the developer experience smooth.

* * *



<h2 id="what-this-means-for-you"><strong>What this means for you</strong></h2>



1.  <strong>Clone and build Skyvern</strong> like before — only now it’s way faster.
2.  <strong>Contribute confidently</strong> knowing your local setup won’t slow you down.
3.  <strong>Enjoy a smoother dev loop</strong> when testing, fixing, or extending Skyvern.

Try it out now: `pip install skyvern`
