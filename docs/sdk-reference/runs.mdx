Start a one-off browser task with `run_task`, then use the run methods with the `run_id` it returns. The run methods work for task runs (`tsk_…`) and agent runs (`wr_…`) alike.

Every method here also accepts `request_options` (Python) or a final `requestOptions` argument (TypeScript) to override the timeout, retries or headers for one call; see [request options](/sdk-reference/overview#request-options).

<CodeGroup>
```python Python
import asyncio

async def main() -> None:
    skyvern = Skyvern(api_key="YOUR_API_KEY")
    result = await skyvern.run_task(prompt="Find the top post on Hacker News and return its title")
    print(result)


asyncio.run(main())
```

```typescript TypeScript
import { Skyvern } from "@skyvern/client";

});
console.log(result);
```
